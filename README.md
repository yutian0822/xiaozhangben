# 小账本

对公垫付 + 个人生活，两本账。单页 PWA，数据只存在浏览器本地（localStorage），不联网、不上传。

## 文件

- `index.html`：全部界面与逻辑（无依赖、无构建）
- `manifest.webmanifest`：主屏图标与全屏设置
- `sw.js`：离线缓存（只缓存界面，不碰账目数据）
- `icons/`：180 / 192 / 512 三种尺寸

## 本地预览

```bash
python3 -m http.server 8765
# 电脑：http://127.0.0.1:8765
# 手机（同一 Wi-Fi）：http://<本机局域网 IP>:8765
```

## 功能

- 两本账切换：对公垫付 / 个人生活
- 对公：项目、发票（无/普票/专票）、报销状态（待报 / 已提交 / 已到账）、支付方式
- 个人：分类、支付方式
- 按月汇总：对公看「本月垫付 / 待报销 / 已提交 / 已到账」，个人看「本月支出 / 日均 / 有支出天数」
- 状态筛选、按日分组、点条目改或删
- 导出本月 CSV、全部 CSV、完整 JSON 备份；导入 JSON 合并恢复
- 离线可用，加到主屏幕后全屏打开


## 导入微信 / 支付宝账单

设置 → 导入账单 → 选文件，CSV 和 xlsx 都能直接读，不用转换。

- 微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账，邮箱收到的 xlsx 直接拖进来即可（把文件传到手机：AirDrop / 微信文件传输助手都行）。
- 支付宝：我的 → 账单 → 右上角 → 开具交易流水证明，给的是 CSV（常为 GBK 编码，程序会自动尝试解码）。

导入时选「对公垫付」或「个人生活」，会自动跳过重复（按交易单号与 日期+金额+对方 指纹）。只导支出，收入行忽略。

## 用链接预填一笔

链接支持参数，从短信、书签、别的 App 打开都能用：

```
https://<你的地址>/?金额=35.5&备注=打车&类型=个人&分类=交通&auto=1
```

- `金额` / `amount`（必填）
- `类型` / `ledger`：`biz` / `对公` 或 `me` / `个人`
- `备注` / `note`、`分类` / `cat`、`日期` / `date`（YYYY-MM-DD）
- `auto=1`：直接保存，不弹表单

## 发布到 GitHub Pages

1. GitHub 新建仓库 `xiaozhangben`，选 Public，不要勾 README。
2. 仓库首页点「uploading an existing file」，把本文件夹里的 `index.html`、`sw.js`、`manifest.webmanifest`、`icons/`、`README.md` 拖进去，提交。
3. Settings → Pages → Source 选「Deploy from a branch」，分支 `main`、目录 `/ (root)`，Save。
4. 等一分钟，页面顶部给出 `https://<用户名>.github.io/xiaozhangben/`。
5. 手机 Safari 打开它 → 分享 → 添加到主屏幕。

发布后手机独立使用，电脑可以关。更新版本时替换文件、并把 `sw.js` 里的 `CACHE` 版本号加一，手机上重开一次即可。

## 注意

- 清除 Safari 网站数据会连账目一起清掉，定期导 JSON 备份。
- 换手机：新手机打开同一链接，导入备份。
